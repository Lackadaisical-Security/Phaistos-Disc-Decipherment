## 🎯 OUR ANCHORS

### **ANCHOR 1: MINOAN CULTURE (1600 BCE)**
**What we know:**
- Palatial administrative system (centralized bureaucracy)
- Agricultural economy (grain, olive oil, livestock)
- Religious festivals (offerings to deities)
- Scribal class (professional record-keepers)
- Mother goddess worship (Potnia - "Lady")
- Bull cult (sacred animals)
- Maritime trade (ships, merchants)

**Administrative patterns:**
- Authority statement (who authorized)
- Purpose statement (what for)
- Resource listing (what's provided)
- Quantities (how much)
- Validation (official seal)

### **ANCHOR 2: LINEAR A (SAME MINOAN CIVILIZATION)**
**Patterns from Linear A administrative texts:**
```
[Authority marker] + [Resource] + [Quantity] + [Location/Purpose]

Example structure:
"Authority-marker grain-quantity vessel-quantity [for] deity/festival"
```

**Linear A vocabulary that evolved to Phaistos:**
- LA_authority → PD_AUTHORITY (wa-na-ka)
- LA_scribe → PD_SCRIBE (ka-ra-te)
- LA_grain → PD_GRAIN (si-to)
- LA_vessel → PD_VESSEL (a-mi-ni-so)
- LA_livestock → PD_LIVESTOCK (bo-pi)
- LA001 → PD001 (numerical unity)

### **ANCHOR 3: HISTORICAL CONTEXT**
**Phaistos Palace context:**
- Major Minoan palatial center
- Religious/administrative hub
- Storage facilities (pithoi - large jars)
- Scribal archives
- Festival celebrations

**Expected content for "festival offering record":**
- Lists of provisions
- Quantities of goods
- Religious purposes
- Official validation

## 💎 LINGUISTIC ANCHORS FROM LINEAR A

**Administrative formula structure:**
```
AUTHORITY + COMMODITY + QUANTITY + PURPOSE = Standard Minoan admin text
```

**Common Minoan phonetic patterns:**
- CV syllables (consonant-vowel: ka, te, si)
- Word-final vowels common
- Reduplication for emphasis (te-te-te)
- Particle markers (-ma, -qe for "and")

**Expected vocabulary themes:**
- Authority: wa-na-ka, ka-ra-te
- Commodities: si-to, a-mi-ni-so, bo-pi
- Religious: po-ti-ni-ja, te-me-no, te-o-po-ri-ja
- Quantities: e-ne (one), numerical markers
- Actions: a-pe-do-ke (gave/delivered), to-so (total)
